# DOTS-N-BOXES — Игра наподобие "крестики-нолики"

Мульти-пользовательская игра. Для на первом этапе будет возможность играть только вдвоём, а дальше видно будет.
Данный проект  

Правила такие:
1. Игровое поле - поле из клеток. Пока что 9х9 клеток. Границы поля изначально зачерчены.
2. Каждый игрок по очереди зачеркивает свободные границы клеток внутри поля.
3. Если какой-то игрок зачертил последнюю границу клетки, то его значок ставится внутри клетки и игрок получает возможность сделать ещё один ход.
4. Если все клетки заняты, то выигрывает тот, у кого больше значков на поле.

## 🚀 Технологии

### Back-end
- **Fastify** - Серверный фреймворк
- **TypeScript** — типизация
- **TypeORM** + **PostgreSQL** — база данных
- **Socket.IO** — WebSocket-соединения для обмена ходами
- **JWT + bcrypt** — аутентификация
- 
### Front-end
- **React 19** + TypeScript
- **Vite** — сборка
- **TanStack Query** — управление данными
- **Zustand** — глобальное состояние маркеров
- **Axios** — HTTP-запросы
- **Vitest** — тестирование
